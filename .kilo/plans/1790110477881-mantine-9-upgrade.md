### 4b. Update editor extensions for Tiptap 3

**Files:**

- `src/components/text-editor/TextEditor.tsx:23-33`
- `src/app/apps/chat/page.tsx:74-81`

In Tiptap 3, `StarterKit` no longer includes `link` by default. Use `StarterKit.configure({ link: false })` and add the `@mantine/tiptap` `Link` extension explicitly. `Underline`, `Superscript`, `SubScript`, `Highlight`, `TextAlign` remain as separate extensions.

Example for TextEditor:

```tsx
extensions: [
  StarterKit.configure({ link: false }),
  Underline,
  Link,
  Superscript,
  SubScript,
  Highlight,
  TextAlign.configure({ types: ['heading', 'paragraph'] }),
],
```

Example for Chat:

```tsx
extensions: [
  StarterKit.configure({ link: false }),
  Link,
  Placeholder.configure({ placeholder: 'Type your message' }),
],
```

### 4c. Remove direct `@tiptap/extension-link` usage

If any file imports `@tiptap/extension-link` directly, replace with `Link` from `@mantine/tiptap`.

## Step 6 — Verify no other Mantine 9 migration issues

Check for:

- `useLocalStorage` / `useSessionStorage` usage without `defaultValue` (now returns `T | undefined`)
- `useHeadroom` usage (now returns `{ pinned, scrollProgress }`)
- `useFullscreen` → `useFullscreenElement` / `useFullscreenDocument`
- `useMouse` → `useMouse` / `useMousePosition`
- `useMutationObserver` → `useMutationObserverTarget`
- Any `Popover` / `Tooltip` with `positionDependencies` prop (remove it)
- Any `Notifications` component that needs `pauseResetOnHover="notification"` to preserve old behavior
