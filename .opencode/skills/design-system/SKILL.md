# Design System

Design system guidance for this Mantine-based dashboard.

## When to Use

- Building new UI components
- Reviewing visual consistency
- Planning theme changes

## Guidelines

- Use Mantine theme tokens instead of hardcoded colors
- Keep spacing, typography, and color usage consistent
- Support both light and dark themes intentionally
- Treat data visualization as part of the design system
- Avoid generic template-looking UI
